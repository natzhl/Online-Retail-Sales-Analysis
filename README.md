# Online Retail Sales Analysis

Анализ продаж интернет-магазина на основе Kaggle датасета “Online Retail Dataset”.

_____________________________
Цель проекта — выявить сезонность продаж, определить причины падения выручки и найти ключевые товары и страны, формирующие основную часть дохода компании.

## 🛠 Tools
* Python (pandas) - очистка и подготовка данных (удалены возвраты, нулевые цены и строки без CustomerID)
* Excel - сводные таблицы, графики и анализ.
_____________________________
В рамках анализа были выполнены следующие шаги:
* анализ динамики выручки по месяцам
* выявление причины падения продаж (сравнение количества заказов и средних чеков по месяцам)
* выявление ключевых позиций товаров
* анализ выручки по странам

## Выводы
* Продажи имеют выраженную сезонность с периодами снижения
* Основная причина падения выручки — сокращение количества заказов
* Нет товаров, которые ярко выраженно вносят большой вклад в общую сумму выручки
* Бизнес в значительной степени зависит от одной страны (Великобритании), которая вносит самый большой вклад
